# Faater v0.1.0 — source preview (not a launch)

Faater is a free, public, Qur'an-grounded Q&A system for English and Persian.
The answer path is deterministic: retrieval, fixed gates, and verse cards. No AI
provider is called at runtime.

This is a **source preview**, published as a GitHub pre-release. It is not a
launch, not a stable release, and not certified.

## What ships

- **M0 — corpus and evaluation.** Pinned Tanzil Arabic (SHA-256 checked),
  QuranEnc `english_saheeh` 1.1.2 and `persian_ih` 1.1.3, basmala segmentation,
  trilingual normalization, deterministic corpus and D1 seed generation.
- **M1 — answer API.** Cloudflare Worker on D1/FTS5: explicit verse and surah
  references, fixed input guards, fixed refusal and boundary copy, verse cards
  with Arabic and both translations, Turnstile-aware HTTP surface, and
  fail-closed CORS.
- **M2 — frontend.** Static EN/FA UI with RTL, labelled translation editions,
  disclosed footnotes, no analytics, no external fonts.
- **Evaluation assets.** 100-item pilot, frozen 100-item blind set, burned scope
  holdout, retrieval reports, and concept-layer ablations.

The release archive is source only. It does not include a prebuilt D1 seed,
hosted corpus, or build output.

## Evidence — pilot only, with limits

The pilot has 100 items: 66 answerable items and 34 should-refuse items; EN and
FA are paired translations. It is the development set. It is **not** the blind
set, has not been scholar-reviewed, and supports no certification claim.

| metric | in-memory | D1/FTS5 |
|---|---:|---:|
| hit@5 | 28.8% (19/66) | 30.3% (20/66) |
| direct hit@5 | 34.0% (17/50) | 34.0% (17/50) |
| paraphrase hit@5 | 12.5% (2/16) | 18.8% (3/16) |
| MRR | 0.215 | 0.229 |

- `npm test`: 167 pass (142 pipeline + 25 worker).
- Concept-layer ablation: paraphrase hit@5 6.3% → 12.5%; direct hit@5
  36.0% → 34.0%, exactly the pre-registered 2.0-point allowance. PASS.
- Blind set: frozen and verified, **not run**. No blind metric is quoted.

## Known blockers

- **BUG-001 (open).** Persian `شراب و قمار` puts Qur'an 2:219 at rank 7
  in-memory / 8 in D1, below the five-card cutoff. English "alcohol and
  gambling" finds it at rank 3; English "wine" at rank 7; Persian `شراب` at
  rank 20. A targeted fix is planned for v0.1.1; a reviewed verse→subject
  relevance layer is planned for v0.2.0.
- **G1 scope classifier held.** Independent holdout Quran recall 92.5%
  (EN 95.0%, FA 90.0%) against a 97% target; built but not wired. A fiqh
  question can retrieve prayer verses and be answered.
- **G2/G3 missing.** No learned retrieval floor or answerability score; refusal
  happens only when retrieval returns nothing.
- **Abuse controls incomplete.** Turnstile and CORS are wired; per-IP daily caps
  and the Cloudflare WAF rate-limit rule are not.
- **Copy review pending.** Persian UI and fiqh/crisis copy are UNREVIEWED; no
  sensitive-verse metadata exists.
- **Legal review pending.** No code licence is granted by this pre-release.
- **M3/M4 not implemented.** No dense retrieval, concept cards, or generated
  prose.
- **Blind set not reviewed or run.** Any retrieval change invalidates the frozen
  set; a new set is required before any certification claim.

## Staging is not a launch

The test instance is https://faater.verafired.workers.dev. It is Turnstile-gated,
has no SLA, and may be reset. Do not present it as a launch, a stable service,
or a production deployment.

## Reproduce

Requires Node.js >= 24.

```bash
pnpm install
pnpm pipeline
npm test
pnpm eval
pnpm eval:d1
npx wrangler deploy --dry-run
```

`data/build/` is generated from the pinned sources and is not committed. The
evaluation report is deterministic except for its `generated` and `elapsedMs`
fields.
